For each, I want the current academic/industry consensus, known failure modes, and concrete recommendations:### 1. Markdown Vault ArchitectureShould the Obsidian vault be:- (A) **System of record** (gbrain model): git repo is primary, agent reads/writes markdown, database caches search indices.
