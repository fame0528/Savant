# Hivemind Architecture: Savant's Collective Intelligence System> **Status:** Production (v0.3.4)> **Crates:** `savant_agent` (SwarmController), `savant_ipc` (CollectiveBlackboard, SwarmBlackboard), `savant_cognitive` (ExecutiveMonitor), `savant_memory` (MemoryEngine)---## OverviewThe Savant hivemind is a collective intelligence system where multiple autonomous AI agents operate as a unified cognitive entity. Agents share zero-copy memory, vote on destructive operations, and drive each other's behavior through a continuous heartbeat loop with threshold-based activation.Every component runs on a single machine. No network overhead. No serialization. Pure memory access.---## Architecture```text┌─────────────────────────────────────────────────────────────────┐│                     SWARM CONTROLLER                            ││                     (swarm.rs)                                  ││  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌───────────────┐  ││  │ Nexus    │  │ Memory   │  │ ECHO     │  │ Skill Manager │  ││  │ Bridge   │  │ Engine   │  │ WASM     │  │ + Security    │  ││  └──────────┘  └──────────┘  └──────────┘  └───────────────┘  ││  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌───────────────┐  ││  │ Collective│  │ Swarm    │  │ Schema   │  │ Credential    │  ││  │Blackboard│  │Blackboard│  │ Index    │  │ Broker        │  ││  └──────────┘  └──────────┘  └──────────┘  └───────────────┘  │├─────────────────────────────────────────────────────────────────┤│                     AGENT LAYER (1-128 agents)                  ││  ┌──────────────────────────────────────────────────────────┐  ││  │ Agent 1                Agent 2               Agent N     │  ││  │ ┌──────────────┐      ┌──────────────┐                  │  ││  │ │ AgentLoop    │      │ AgentLoop    │                  │  ││  │ │ ├─ LLM       │      │ ├─ LLM       │                  │  ││  │ │ ├─ Tools     │      │ ├─ Tools     │                  │  ││  │ │ ├─ HyperCausal│     │ ├─ HyperCausal│                 │  ││  │ │ ├─ ECHO      │      │ ├─ ECHO      │                  │  ││  │ │ └─ Security  │      │ └─ Security  │                  │  ││  │ └──────────────┘      └──────────────┘                  │  ││  │ ┌──────────────┐      ┌──────────────┐                  │  ││  │ │ Heartbeat    │      │ Heartbeat    │                  │  ││  │ │ Pulse        │      │ Pulse        │                  │  ││  │ └──────────────┘      └──────────────┘                  │  ││  └──────────────────────────────────────────────────────────┘  │└─────────────────────────────────────────────────────────────────┘```---## Core Components### 1. No network, no serialization, no copy overhead.1. **Threshold-based activation:** Agents only invoke LLM when environment changes meaningfully. Time decay ensures forced pulse every ~8.57 minutes.1. **Dream integration:** During idle periods, agents run NREM (consolidation) and REM (exploration) cycles. Heartbeat skips during dream to avoid resource contention.1. **Solo agent quorum=1:** When only one agent exists, consensus quorum is auto-set to 1 to prevent deadlock.1. **Retry-with-suffix for Windows:** Stale shared memory segments handled by retrying with incremented service names.1. **Dual blackboard separation:** Collective handles swarm-wide consensus/metrics. Swarm handles per-agent state. Different access patterns, different update frequencies.1. **Ephemeral credentials:** No static API keys stored. CredentialBroker injects per-task tokens. JWT secrets are crypto-random, in-memory only.1. **Cognitive lens rotation:** 18 lenses with 2:1 weighting for emergent vs operational. Critique lens for adversarial self-examination prevents echo chambers
